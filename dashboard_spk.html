Pemilihan supplier dengan metode Simple Additive Weighting (SAW) · Praktikum Terintegrasi II, Kelompok V

Data supplier

Unggah file Excel atau CSV berisi bobot dan nilai tiap supplier. Perhitungan SAW dan grafik langsung diperbarui di browser Anda, tanpa mengirim data ke mana pun.

Format file yang dibaca
  • Baris 1: judul kolom. Kolom pertama bebas (mis. "Alternatif"), kolom berikutnya adalah kriteria, mis. "C1 Harga per set".
  • Baris "Jenis": isi Cost (makin kecil makin baik, mis. harga) atau Benefit (makin besar makin baik) untuk tiap kriteria.
  • Baris "Bobot": boleh 25, 25%, atau 0,25. Jika totalnya bukan 1 atau 100, bobot dinormalkan otomatis.
  • Baris berikutnya: satu supplier per baris, kolom pertama nama supplier, sisanya angka. Harga dan rating boleh memakai koma atau titik desimal.
  • Minimal 2 supplier dan 2 kriteria, maksimal 7 kriteria. Nilai cost harus lebih dari 0.
  • Dari file CSV, tulis angka tanpa pemisah ribuan (129000) agar tidak salah baca. File Excel aman.

Peringkat nilai preferensi (Vi)

Bobot kriteria

Dari mana nilai tiap supplier berasal

Matriks ternormalisasi dan nilai akhir

Warna menunjukkan rij (0 sampai 1, makin gelap makin baik). Vi = jumlah bobot × rij. Urut dari peringkat tertinggi.

Rumus: kriteria cost rij = nilai minimum / xij, kriteria benefit rij = xij / nilai maksimum, lalu Vi = jumlah (bobot × rij), mengikuti Mardika dan Fauzi (2024). Peringkat 1 adalah Vi terbesar. Nilai ditampilkan 4 desimal.
